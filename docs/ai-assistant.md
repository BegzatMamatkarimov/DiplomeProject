# ИИ-ассистент: дизайн

## Для кого
- **Студент**: «Почему у меня упал GPA?», «Как поднять рейтинг?», «Какие хакатоны мне подходят?», «Я в зоне риска?»
- **Преподаватель**: «Кто в моих группах в зоне риска?», «Сводка по посещаемости по предмету X».

## Архитектура
```
UI (чат) → /api/chat → AssistantService
                         ├─ системный промпт (роль, язык пользователя, правила)
                         ├─ tools (только чтение, с проверкой доступа по сессии)
                         └─ LLMProvider (OpenAI-совместимый клиент)
                              ├─ Gemini (Google AI Studio)  ← по умолчанию в MVP
                              ├─ Groq
                              └─ OpenRouter (:free модели)
```
- Провайдер выбирается через `Setting.ai.defaultProvider`. Если провайдер вернул 429 или 5xx, запрос автоматически уходит следующему по приоритету (фолбэк).
- Ключи хранятся только в `.env`: `GEMINI_API_KEY`, `GROQ_API_KEY`, `OPENROUTER_API_KEY`.
- Лимиты бесплатных тарифов меняются, перед реализацией проверить актуальные.

## Tools (tool calling)
Каждый tool получает `session` и сам ограничивает данные по роли. Модель **никогда** не получает SQL и не видит чужие данные.

| Tool | Кто может | Что возвращает |
|---|---|---|
| `get_my_performance` | студент | GPA, оценки по предметам, посещаемость, динамика по семестрам |
| `get_my_rating` | студент | место в группе в режимах GPA и GPA_PLUS |
| `get_my_risk` | студент | уровень риска и причины |
| `get_my_achievements` | студент | достижения и их статусы |
| `list_events` | все | мероприятия из каталога (фильтр: тип, даты, теги) |
| `get_students_at_risk` | преподаватель, эдвайзер | список студентов в зоне риска в пределах доступа |
| `get_offering_stats` | преподаватель | статистика по своему предмету |

## Правила системного промпта
- Отвечать на языке интерфейса пользователя (ru, kk, en).
- Опираться только на данные из tools. Если данных нет, так и сказать.
- Рекомендации давать конкретные: какой предмет подтянуть, сколько пропусков допустимо, какие мероприятия из каталога подходят.
- Не ставить диагнозов и не давать обещаний о решении деканата.

## Полная версия
- ML-модель риска (Python, FastAPI + scikit-learn: логистическая регрессия или градиентный бустинг) заменяет правила, `method = ML`. Метрики для диплома: ROC-AUC, precision и recall на демо-данных или открытых датасетах.
- Рекомендации мероприятий: сопоставление тегов события и сильных предметов студента.
- Переключатель модели в UI чата.
