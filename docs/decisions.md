# Архитектурные решения (ADR-lite)

| # | Решение | Почему | Альтернативы |
|---|---|---|---|
| 1 | Next.js full-stack + TypeScript | Один проект: проще деплой, быстрее генерация через Claude Code | Spring Boot + React, FastAPI + React |
| 2 | Форк Lama Dev School Management Dashboard | Готовые ролевые дашборды и CRUD, экономия 2–3 дней на MVP | С нуля |
| 3 | PostgreSQL в локальном Docker | Работает без внешних сервисов, выглядит профессионально | Supabase, Neon |
| 4 | Auth.js (credentials) вместо Clerk | Работает офлайн, без внешнего аккаунта, полный контроль над ролями | Clerk |
| 5 | shadcn/ui + Tailwind | Стиль Linear и Vercel, тёмная тема, компоненты в коде проекта | MUI, Ant |
| 6 | Только бесплатные LLM через OpenAI-совместимый слой | Требование заказчика, переключение моделей | Платный API |
| 7 | ИИ только через типизированные tools | Безопасность: доступ по ролям, нет SQL-инъекций через промпт | Text-to-SQL |
| 8 | Риск: правила в MVP, ML в полной версии | Быстрый MVP; ML даёт «интеллектуальную» часть для диплома | Сразу ML |
| 9 | Рейтинг с двумя режимами (GPA, GPA_PLUS) | Требование: хакатоны должны влиять на рейтинг | Только GPA |
