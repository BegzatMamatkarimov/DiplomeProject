# Описание продукта (v0.3, согласовано)

**Тема:** Интеллектуальная информационно-аналитическая система мониторинга успеваемости и достижений студентов с ИИ-ассистентом.
**Формат:** работа на заказ. MVP показываем заказчику как можно скорее (не позже ~14.11.2026), он затем показывает руководителю. Полная версия до января 2027.
**Реализация:** только через Claude Code. Планирование на Opus, код на Sonnet.
**Текст диплома** пишет другой человек, по нашим документам и самой системе.

---

## 1. Требования заказчика
- Участие студентов в хакатонах и проекты с хакатонов.
- Красивый современный дизайн.
- Остальное определяем сами.

## 2. Платформа
- Только веб.
- Интерфейс на трёх языках: русский (по умолчанию), казахский, английский.
- Система не привязана к конкретному вузу.
- Светлая и тёмная тема с переключателем.
- Запуск локально через Docker. Хостинг позже, если понадобится.
- Стек: Next.js + TypeScript + Tailwind + shadcn/ui + Prisma + PostgreSQL; основа — форк шаблона Lama Dev (см. `decisions.md`).

## 3. Роли
| Роль | Что делает |
|---|---|
| Студент | Видит свои оценки, GPA, посещаемость, рейтинг, расписание и достижения. Добавляет достижения. Пользуется ИИ-ассистентом. |
| Преподаватель | Ведёт оценки и посещаемость по своим предметам. Пользуется ИИ-ассистентом. |
| Эдвайзер | Закреплён за группой. Подтверждает достижения студентов группы. Видит риски и успеваемость группы. |
| Деканат (он же админ) | Видит аналитику по всем группам и курсам. Создаёт пользователей и группы, ведёт справочники и каталог мероприятий (хакатоны и др.). |

## 4. Успеваемость
- Оценки, GPA, посещаемость, рейтинг группы, расписание.
- Ввод данных: вручную и импортом из Excel. Для тестов используем демо-данные.
- **Рейтинг с фильтром**: (а) только по GPA; (б) GPA плюс баллы за подтверждённые достижения.

## 5. Достижения
- Типы: хакатоны, олимпиады, сертификаты, публикации, спорт.
- Хакатон: название, дата, место или результат, команда, проект, ссылка на GitHub, сертификат.
- Процесс: студент добавляет, **эдвайзер группы подтверждает**. Баллы в рейтинг дают только подтверждённые достижения.

## 6. ИИ-ассистент (для студентов и преподавателей)
- Отвечает на вопросы по оценкам.
- Даёт рекомендации и советы, как улучшить успеваемость и рейтинг.
- Предупреждает о риске отчисления.
- Советует хакатоны из **каталога, который ведёт деканат**.
- Модели только бесплатные, с возможностью переключаться между несколькими.

## 7. Риск отчисления
- MVP: формула по правилам (низкий GPA, пропуски, долги).
- Полная версия: ML-модель («интеллектуальная» часть для диплома).

## 8. Дизайн
- Ориентиры: Apple, Nothing, Tesla, Linear, Vercel. Современный, но без пафоса.
- Предметная область: Platonus (журнал, транскрипт).

---

## 9. MVP (согласовано)
- Вход под четырьмя ролями (демо-аккаунты).
- Дашборд студента: GPA, оценки, посещаемость, рейтинг, достижения.
- Достижения и хакатоны: студент добавляет, эдвайзер подтверждает.
- Эдвайзер и преподаватель: список студентов с отметкой риска (по правилам).
- Деканат: базовая аналитика (графики по группам).
- ИИ-ассистент: чат на одной бесплатной модели, отвечает по данным студента.
- Русский интерфейс, переводы подключаются позже без переделки. Переключатель темы.
- Демо-данные.

## 10. Полная версия (до января)
- Импорт из Excel.
- Расписание.
- Три языка интерфейса.
- Переключение между ИИ-моделями.
- Рекомендации хакатонов из каталога.
- ML-модель риска.
- Отчёты и экспорт.
- Уведомления.
